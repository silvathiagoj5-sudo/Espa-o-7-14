## Publicação no GitHub Pages
1. Extraia o ZIP.
2. Envie `index.html` e a pasta `assets` para a raiz do repositório.
3. Abra Settings → Pages.
4. Selecione Deploy from a branch, branch `main`, pasta `/ (root)` e salve.
