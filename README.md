# Espaço 7 14 — Site demonstrativo

## Publicação
1. Extraia o ZIP.
2. Envie `index.html` e a pasta `assets` para a raiz do repositório GitHub.
3. No GitHub, abra Settings → Pages.
4. Em Build and deployment, selecione Deploy from a branch.
5. Escolha a branch `main` e a pasta `/ (root)`, depois salve.

## Antes de publicar
- Confirmar com a empresa se o endereço, horários, telefone, Instagram e serviços continuam corretos.
- Confirmar se a unidade Jardins existe e, se sim, enviar endereço e telefone oficiais. A pesquisa atual confirmou publicamente a unidade Moema; o Linktree público atual apresenta um único contato para agendamento.
- Substituir as imagens de referência hospedadas no Unsplash por fotos autorais aprovadas pela empresa. As imagens atuais são ilustrativas, não são fotos dos trabalhos do Espaço 7 14.
- Validar com a empresa a descrição de higiene, produtos, protocolos e cursos.
- Confirmar se o WhatsApp de cursos (11) 97801-0300 continua ativo.

## Observação
Site estático, responsivo e sem backend. Os botões de WhatsApp abrem conversas com mensagens pré-preenchidas.
